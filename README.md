# Cyber-internship
Internship Project Report: Cybersecurity Lab Setup

Organization: Networkwalks
Project: Module 1 – VirtualBox and Kali Linux Lab Setup

As part of my cybersecurity internship with Networkwalks, I completed Project Module 1, which involved setting up a virtual cybersecurity testing environment using Oracle VirtualBox and Kali Linux.

The project involved configuring a NAT Network using the "10.0.0.0/24" subnet, assigning Kali Linux the IP address "10.0.0.2/24", and configuring virtual machine features such as clipboard sharing, drag-and-drop, and shared folders. The environment was intended to provide internet access and support future cybersecurity practical exercises.

Through this project, I gained practical experience in virtualization, IP addressing, network configuration, and Kali Linux environment setup. I also developed a better understanding of the importance of troubleshooting and preparing a controlled environment for ethical hacking practice.

Conclusion: This project represents an important step in my cybersecurity internship journey with Networkwalks, providing a foundation for further learning in network analysis, vulnerability assessment, and ethical hacking.
